# FLux

FLux is a renderer, and hdFlux, in `Hydra/`, is its Hydra render delegate.

- Before you change the core API, hdFlux, or how a backend derives from the scene, read [architecture](docs/architecture.md).
- Before you write code that reads scene content or takes arguments from calling code, read [input](docs/input.md).
- Before you write code or a comment, or name a new entity, read [conventions](docs/conventions.md).
- Before you build or test, read [build](docs/build.md).
